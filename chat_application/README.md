"Set-up Steps"
## We will use the Firebase CLI to set up the firebase for a flutter project
1. [Install the node.js ](https://nodejs.org/en) Don't forget to check the box for installing all necessary component for the chocolate this will install and add all the required things to your system path
2. npm install -g firebase-tools run this command this will install the FIREBASE command in your system. After this command we can now use all the FIREBASE command like:
 - firebase login
 - firebase projects:list
3. Project configuration with the firebase
 - Run [dart pub global activate flutterfire_cli] - to activate the flutter fire CLI
 - Run [flutterfire configure --project="PROJECT_NAME_WITH_ID"]
